EXPERIMENT 2 - CSS3

This is the CSS3 extension of the Heatwave Intelligence HTML5 portal.

Task 1: index.html - inline CSS on header, h1 and p.
Task 2: navigation.html - internal CSS for horizontal navigation and hover.
Task 3: assets/style.css - external site-wide theme.
Task 4: Monitoring Categories sidebar card with border, shadow, padding, radius and hover.
Task 5: Heat Risk cards use width, margin, padding, border, inline-block, background and shadow.
Task 6: media.html image gallery uses equal image sizing, border, spacing, transition and scale().
Task 7: forecast.html uses border-collapse, header styling and nth-child(even).
Task 8: subscribe.html uses form.css, :focus, :hover and border-radius.
Task 9: layout-demo.html uses Flexbox for header/sidebar/content/footer layout.
Task 10: index.html has an animated priority alert using @keyframes, text-shadow and box-shadow.

The assignment sheet uses bookstore examples such as book.html and price lists.
These have been adapted to the Heatwave Intelligence use case from Experiment 1.

No Bootstrap is used because the practical specifically asks to demonstrate CSS3
features directly. The post-lab question can be answered separately.
